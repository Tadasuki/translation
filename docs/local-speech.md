# 本地语音

在 **设置 → 常规 → 语音朗读** 中选择 **本地自然语音 · Qwen3-TTS**，点击“下载并启用本地语音”。首次安装需要网络和约 2GB 磁盘空间，完成后原文、译文和单词 TTS 在本机生成，不需要 API Key。

当前支持 Apple 芯片 Mac。中文默认 Serena，英文默认 Ryan；可以分别选择音色并试听。词典有真人单词录音时继续使用该录音，无录音时使用所选语音引擎。本地语音失败时会显示原因，不自动改用在线语音。

模型加载及 Metal 预热在后台进行；界面显示“本地语音已就绪”后即可播放。语音边生成边播放，同一文本和音色在本次运行期间有有界缓存。模型空闲三分钟后释放，下一次新文本朗读会重新加载。播放期间切换文本、关闭浮窗或停止试听会取消旧请求。

运行环境和模型位于应用用户数据目录的 `local-tts` 子目录。Python 运行环境独立安装，不修改系统 Python，也不监听本机网络端口。应用退出时会停止语音子进程。模型固定到版本修订，打包时只携带 worker 和依赖清单，模型由首次设置下载。

模型：[Qwen3-TTS 0.6B CustomVoice 4bit](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-0.6B-CustomVoice-4bit)，运行库：[MLX Audio](https://github.com/Blaizzy/mlx-audio)。
