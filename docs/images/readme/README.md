# README visual assets

These images show the current application renderer with illustrative vocabulary and translation content. They contain no desktop background, browser toolbar, real account data, or credentials.

- `raw/`: 2× window-only captures of Settings, light/dark appearance, English UI, translation, history, vocabulary, review, export, and local voice settings.
- `hero.png`: overview composition using the Settings and popup captures.
- Other root PNGs: presentation layouts using the corresponding raw window capture, with typography, a neutral backdrop, and a soft shadow. The hero applies background blur behind the transparent popup for legibility; application content is unchanged.

The captures use the cross-platform window controls; native macOS controls and translucent materials depend on the host OS. Demo content does not imply a translation-quality benchmark. Fonts are rendered from the capture machine and are not distributed as font files.

Updated for the v1.0.0 interface on 2026-11-01. Keep the source UI and screenshots in sync when replacing these assets.
